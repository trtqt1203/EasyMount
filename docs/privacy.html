Privacy policy · Effective 30 October 2026 · Updated 31 October 2026

EasyMount is a free, open-source Windows desktop application maintained through the trtqt1203/EasyMount project. This policy explains how the application and this project website handle information. EasyMount is not affiliated with Google, Microsoft or Dropbox.

Information accessed and why

  • Account identity: after you sign in, EasyMount may read your email address to suggest an account display name. You may replace that name.
  • Cloud file data: names, paths, metadata, available storage and file contents are accessed to list, mount, read, cache and, when enabled by you, write or delete files in the cloud locations you configure.
  • Authentication: OAuth access/refresh tokens or credentials entered for supported protocols allow the application to access your configured cloud storage. Passwords for Google/Microsoft browser sign-in are entered on the provider's own pages.
  • Local configuration and logs: drive labels, source order, mount letters, account settings, mount recovery records, cache and operational logs are stored on your computer. Logs may contain file paths and service error details.

Google user data and permissions

For Google Drive, EasyMount requests read-only Drive access when you choose read-only authorization, or full Drive access when you enable uploading and editing. Broad Drive access is needed to mount existing Drive files and support file operations; it is not limited to files created by EasyMount. A mounted drive defaults to read-only separately from the OAuth permission selected.

EasyMount's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used to provide the user-facing storage features you request. It is not sold, used for advertising, or used to train generalized AI or machine-learning models.

Storage and transfers

The desktop app uses rclone to communicate with your chosen cloud providers and their authentication/content delivery services. The project does not operate an intermediary server that receives your cloud files or tokens. If you configure writes, copies, moves or deletion, data is sent to or changed at the selected provider as needed for that operation. Different sources in a merged drive can belong to different providers; new files follow your source priority settings.

Configuration, credentials, logs and cached file contents are stored under %LOCALAPPDATA%\EasyMount by default, or an explicitly selected data directory. Mount recovery controller secrets are protected with Windows DPAPI for the current Windows user. Cloud account configuration can contain usable authentication tokens. EasyMount does not promise application-level encryption of these files. Protect your Windows account, device and backups, and do not share your configuration files.

Retention and deletion

Local data remains until you remove it. Uninstalling EasyMount preserves configuration and cache. First wait for pending uploads to finish and safely disconnect drives. You can then remove local application data when no recovery is needed. Deleting cached data before uploads finish can lose files that have not reached the cloud.

You can revoke Google's authorization in your Google Account connections, or use the corresponding settings at another provider. Revocation prevents future authorized access but does not erase existing local cached copies or cloud files. Cloud retention is governed by the provider. Removing a local account does not itself delete your files from the cloud.

Sharing, support and telemetry

The released application has no developer-operated analytics or advertising service. The maintainer does not receive your files, identity or tokens through normal app operation. If you choose to submit an issue or diagnostic material, its contents are received by GitHub and may be public. Remove tokens, passwords, personal file paths and private data before sending anything. The maintainer does not need your password or authentication tokens for support.

This website

This static website is hosted by GitHub Pages. It does not include project-operated analytics, tracking scripts or a sign-in form. GitHub may process visitor information such as IP addresses and request metadata for hosting and security under the GitHub privacy statement. Linked cloud-provider websites follow their own privacy policies.

Contact and changes

For privacy questions, contact the maintainer through the project's issue tracker. Do not post sensitive information publicly. Material changes will be published on this page with an updated effective date.
