YOUR CLOUD. YOUR DRIVE.

Từ tài khoản cloud đến File Explorer.

01 / KẾT NỐI

Thêm các tài khoản của bạn

Google Drive, OneDrive, Dropbox và các dịch vụ do rclone hỗ trợ. Có thể thêm nhiều tài khoản cùng dịch vụ; mỗi tài khoản đăng nhập riêng.

02 / SẮP XẾP

Chọn thứ tự ưu tiên

Tạo một ổ gộp, sắp nguồn lên hoặc xuống. File mới vào nguồn đầu tiên đủ chỗ, không chia file và không tự di chuyển file cũ.

03 / SỬ DỤNG

Mở file như một ổ đĩa

Đặt tên và ký tự ổ. Kết nối mặc định chỉ đọc; bật ghi khi cần tải lên và sửa file. Chờ upload hoàn tất trước khi ngắt kết nối.

Dữ liệu đi đến cloud bạn chọn.

EasyMount dùng rclone để kết nối trực tiếp với nhà cung cấp. Token đăng nhập và cache nằm trên máy của bạn. Dự án không vận hành máy chủ trung gian nhận file của bạn.
